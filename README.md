Time Table Maker
**Overview**
Time Table Maker is a Python-based application that helps users generate and manage academic timetables efficiently. The project automates schedule organization and stores timetable data in spreadsheet and CSV formats for easy access and modification.

**Features**
1. Generate and organize class schedules
2. Store timetable data in Excel and CSV formats
3. Simple and easy-to-use workflow
4. Automates timetable management tasks
**Technologies Used**
Python;CSV;Excel (XLSX)
**Files**
main.py – Main application script
data.xlsx – Input data source
MyDatabase.xlsx – Database file
mytt.csv – Generated timetable data
timetable.csv – Schedule output
Purpose:This project was developed to simplify timetable creation and improve schedule management for students and educational institutions.
